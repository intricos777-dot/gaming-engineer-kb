# glTF/GLB Pipeline — Draco, KTX2, gltf-transform, Validation

> Source of truth for delivery: GLB + Draco + KTX2 for runtime, uncompressed
> sources in version control, batch-optimized at build time.

## Format choice

| Format | Use |
|---|---|
| GLB (binary glTF) | our runtime delivery (single file, GPU-ready) |
| FBX | DCC handoff / legacy animation exchange only |
| OBJ | geometry-only exchange |
| USD | scene assembly research only |

## Compression — the exact knobs

**Draco (geometry)** — `KHR_draco_mesh_compression`, ratio 8:1–16:1.
| Params | Default | Aggressive | Notes |
|---|---|---|---|
| quantization position | 14 bit | 11–12 bit | 11-bit visually lossless at game distance |
| quantization normal | 10 bit | 8 bit | |
| quantization texcoord | 12 bit | 10 bit | |
| compression level | 7 | 10 | 8–10 only for final delivery |

**KTX2 / Basis Universal (textures)** — `KHR_texture_basisu`, 4–8× VRAM cut.
- **ETC1S** for albedo/ORM color maps (`toktx --encode etc1s --clevel 4 --qlevel 192`).
- **UASTC** for normal/metallic precision (`toktx --encode uastc --uastc_quality 3`).
- Quality 128 / compression level 2–3 = production; 64–96 + 4–5 for size-critical web.
- ETC1S→BC7/BC5 (desktop), ETC2 (mobile), ASTC (Apple) transcode at load.

## gltf-transform (batch, at build time — not committed)

```bash
npx @gltf-transform/cli \
  optimize raw/model.glb out/model.glb \
  --texture-compress ktx2 --texture-size 1024 --draco
gltf-transform prune in.glb out.glb        # strip unused nodes/materials/accessors
gltf-transform dedup in.glb out.glb        # merge duplicate buffers
gltf-transform resample in.glb out.glb     # drop redundant keyframes
```
- `assets/raw/` = artist/AI sources (committed); `assets/optimized/` = build
  output (**gitignored, regenerated by CI or task**).


## Validation gates (hard)

- `npx gltf-validator asset.glb` → **0 errors** (warnings about unused textures
  acceptable, fix if trivially possible).
- Size targets: characters < 10 MB, props < 5 MB (optimized GLB).
- Power-of-two textures · Normal green (OpenGL +Y) · Non-manifold: 0 ·
  Origins at logical 0,0,0 · Bone names descriptive · Metadata `copyright` set.
- After import: verify draw calls (target 1/1–3 materials per asset), texture
  memory (GPU-native format confirmed), LOD compatibility, collision proxies
  simple (box/capsule).
